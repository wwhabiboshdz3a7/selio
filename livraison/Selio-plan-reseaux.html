10 Codes promo, lien ?code= et parrainage

Créer le code d'un créateur (Selio Admin › Offres)

  • Nom : « Créateur · Prénom », pour s'y retrouver.
  • Code : 3 à 24 caractères, lettres, chiffres et tirets, par exemple SARAH20. Les majuscules ne comptent pas.
  • Remise : en pourcentage ou en montant par échéance, sur les forfaits choisis (proposition : −20 % pendant 3 mois sur Starter et Pro), avec une période et un nombre maximal d'utilisations.
  • Bandeau : désactivé pour un code de créateur (le code reste utilisable sans être annoncé sur le site).
  • Lien à donner au créateur : https://<site>/inscription?code=SARAH20 : le code se remplit tout seul à l'inscription.
  • Suivi : Selio Admin affiche combien d'organisations ont utilisé chaque offre ; on rapproche ce nombre des conversions payantes.
  • Fin de collaboration : désactiver l'offre refuse le code ; ceux qui l'ont déjà appliqué gardent leur remise jusqu'à son terme.
À décider ensemble : un code créateur se cumule-t-il avec l'offre fondateurs ? Ma proposition : non, le client garde la meilleure des deux.

Parrainage

Le lien de parrainage existe déjà (/inscription?parrain=CODE, champ facultatif qui ne bloque jamais l'inscription), et la page Parrainage montre comment il fonctionnera. Le programme n'est pas encore ouvert : aucun mois n'est offert tant qu'on n'a pas décidé de l'activer. Proposition : l'ouvrir aux testeurs de la bêta le 14 décembre, avec un mois offert au parrain quand le filleul paie (jamais cumulé avec une autre remise sur la même échéance, comme le prévoit déjà la facturation).

13 Les règles

  • Collaborations : « Collaboration commerciale » ou « Publicité » écrit clairement sur toute vidéo payée ou contre un avantage (loi française sur l'influence commerciale de 2023).
  • Aucune promesse de gain : pas de « gagne 2 000 € par mois », pas de capture de revenus présentée comme un résultat type.
  • Indépendance : Selio est un outil indépendant, non affilié à Vinted. Ni logo, ni couleurs, ni captures de l'interface de Vinted ; jamais « partenaire officiel ».
  • Chiffres : un chiffre de démonstration porte le mot « exemple » à l'écran. Aucun faux témoignage, aucun faux avis, aucun chiffre de clients inventé.
  • Vie privée : pseudos d'acheteurs et messages réels floutés ; un testeur montré à l'écran donne son accord par écrit.
  • Concurrents : on parle de ce que fait Selio, sans dénigrer personne.
  • Automatisations : on montre que l'utilisateur fixe les règles et garde la main ; on ne montre jamais un achat réel déclenché par Selio.
  • Musique : seulement les bandes son générées par nous ou les sons libres de droits proposés par chaque plateforme.
  • Croissance honnête : pas d'achat d'abonnés, de vues ou de commentaires.
