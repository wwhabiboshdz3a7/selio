# Robustesse avant lancement

Bilan du 26 novembre 2026 : douze cas limites vérifiés un par un sur Selio (application web, API, base), avec un test
automatisé qui fige chaque correction. Règle suivie partout : la validation existe **côté serveur** (zod dans
`@selio/contracts`, services de `@selio/core`, API) **et côté navigateur** (message clair en français sous le champ),
et aucune erreur ne s'affiche en texte technique (« Erreur 500 », « Internal Server Error », pile d'appels, JSON brut)
ni en écran blanc.

« Avant » décrit ce que montraient la lecture du code et les essais au début du travail ; « Test ajouté » renvoie aux
fichiers qui échouent si la correction est retirée.

## Erreurs inattendues et écran blanc

- **Serveur** (`apps/api/src/errors.ts`) : les erreurs de Fastify et de ses extensions (corps vide ou illisible, type de
  contenu inconnu, limite de débit, taille) ont chacune un message en français (`frenchHttpMessage`) ; un corps `null`
  ne fait plus planter les routes (`req.body ?? {}`) ; les erreurs de la base dues à une saisie deviennent des 400.
- **Navigateur** (`apps/web/src/lib/api/client.ts`) : plus jamais « Erreur 500 » ; une page HTML d'un proxy, un corps vide,
  une pile d'appels ou un message anglais sont remplacés par un message clair selon le statut (`httpStatusMessage`) ;
  `errorMessage` masque les erreurs techniques du navigateur (`TypeError`, « Failed to fetch »).
- **Écran blanc** : chaque route a déjà sa frontière d'erreur (`RouteError`, dans la mise en page) ; vérifié sur une adresse
  d'article inexistante (`apps/web/e2e/robustesse.spec.ts`).

## Points laissés à décision

1. **Essai gratuit après suppression du compte** : un nouvel essai de 14 jours démarre avec la même adresse. Aucune règle
   n'existe ; en créer une (empreinte de l'adresse conservée après suppression) demande un avis RGPD.
2. **Adresse du client sur les factures** : absente ; à ajouter si des clients professionnels en ont besoin.
3. **Variable `DOUBLE_SUBMIT_WINDOW_MS`** (API, 4 000 ms par défaut, 0 à 60 000) : durée pendant laquelle une action
   réussie identique est refusée comme doublon. 0 garde seulement la protection pendant le traitement.
